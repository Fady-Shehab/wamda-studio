  • استخدام خصائص CSS المنطقية لضمان توازن العربي والإنجليزي
  • معاينة حية عبر رابط تجريبي قبل أي دفع

منيو QR تفاعلي وطلب عبر واتساب (استضافة مجانية مدى الحياة)

  • يدعم العربي والإنجليزي بدون اشتراك شهري أو عمولة
  • جاهز للاستضافة المجانية الدائمة + رمز QR جاهز للطباعة
150 ج.م تسليم: 45 دقيقة

تطوير سيرة ذاتية ATS بالعربي والإنجليزي + تحسين LinkedIn

إعادة صياغة وهيكلة السيرة الذاتية بتصميم نظيف مقروء لأنظمة الفرز الآلي (ATS) مع تحسين الكلمات المفتاحية لحساب LinkedIn.

  • ملف HTML قابل للطباعة كـ PDF بجودة فائقة + نسخة نصية
  • تعديل فوري وفق المسمى الوظيفي المستهدف
150 – 300 ج.م تسليم: 1–2 ساعة

سكريبتات Excel / Google Sheets / Python + فحص سرعة وحماية موقعك

تنظيف وتوحيد ملفات البيانات، معادلات ذكية، أو فحص سلبي عام (Passive) لرؤوس الأمان HTTP Headers وسرعة الصفحة مع كود الإصلاح الجاهز.

  • ملف إعداد جاهز للنسخ على Vercel / Nginx / .htaccess
  • كود Python موثّق بالكامل وسهل التشغيل
